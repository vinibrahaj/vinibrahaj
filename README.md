## Selected Projects

### [SolviTask — Odoo Service Management](https://github.com/vinibrahaj/odoo-internship)

An Odoo 17 module for managing a plumbing and heating business. It connects customer service requests with job assignment, work tracking, and a management pipeline.

- Separate manager, customer, and plumber roles with server-enforced access rules.
- Job workflows, change requests, service catalogs, and PDF job summaries.
- Docker Compose development environment with Odoo and PostgreSQL.

**Python · XML · Odoo · Docker Compose · PostgreSQL**

### [Bank Management System](https://github.com/vinibrahaj/bank-management-system)

A Java console application supporting account creation, authentication, balance inquiries, fund transfers, transaction statements, and account closure. Includes local file storage, password hashing, an automated simulation, and tests.

**Java · File I/O · BigDecimal · PBKDF2**

### [Codexion](https://github.com/vinibrahaj/Codexion)

A concurrent simulation in C where threads compete for shared resources. The project explores synchronization, deadlock prevention, resource contention, and FIFO/EDF scheduling.

**C · POSIX Threads · Mutexes · Condition Variables · Makefile**

### [Push_swap](https://github.com/vinibrahaj/Push_swap)

A sorting program in C that works with two stacks and a restricted set of operations. It includes multiple sorting strategies, adaptive strategy selection, argument validation, and operation benchmarks.

**C · Data Structures · Sorting Algorithms · Makefile**

### [Fly-In](https://github.com/vinibrahaj/Fly-in)

A drone-routing simulation that plans movement through a network of zones while respecting capacity limits and movement costs. It includes map parsing, route planning, turn-based simulation, and a Pygame replay.

**Python · Graph Algorithms · Simulation · Pygame**

### [Plumbing Services CRM](https://github.com/vinibrahaj/plumbing-crm)

A standalone application with a FastAPI backend, React interface, and SQLite storage. It supports role-based access, service requests, qualified team assignments, and job progress tracking, with GitHub Actions checks for backend tests and the frontend build.

**Python · FastAPI · React · SQLite · GitHub Actions**
